# 🎮 Hangman / Wordle Game (Python)

A word guessing game inspired by Hangman and Wordle, built using Python.

---

## 🚀 Features

* Random word selection
* User guesses letters or words
* Tracks correct and incorrect guesses
* Limited attempts system
* Interactive command-line gameplay

---

## 🛠️ Tech Used

* Python 3

---

## ▶️ How to Run

1. Clone the repository:
   git clone https://github.com/Luck-jp/hangman-wordle-python.git

2. Navigate to the folder:
   cd hangman-wordle-python

3. Run the program:
   python main.py
